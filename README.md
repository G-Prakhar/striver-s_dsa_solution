# Striver's DSA Sheet

A structured repository containing my solutions to **Striver's A2Z DSA Sheet**. This repository is part of my preparation for coding interviews and aims to strengthen my understanding of Data Structures and Algorithms through consistent practice.

## 📌 About

The **Striver's A2Z DSA Sheet** is one of the most popular roadmaps for mastering DSA. It covers all the essential topics required for coding interviews at product-based companies and competitive programming.

This repository contains:

- ✅ Topic-wise solutions
- ✅ Clean and well-commented code
- ✅ Multiple approaches (where applicable)
- ✅ Time and Space Complexity analysis
- ✅ Regular updates as I progress through the sheet
